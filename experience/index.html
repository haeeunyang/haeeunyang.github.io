  • Camera Pose Regression with Deep Learning Spring 2024

    Deep Learning course, Sookmyung Women's University

    • Built an image dataset from indoor video and compared four deep learning architectures (CNN, Transformer, ViT, encoder bottleneck) for pose estimation.

    Team project (3 members). We built a camera-pose dataset from 2,646 frames of a 7-minute indoor video, reconstructing the floor in RealityCapture with 28 control points (2,580 aligned images), removing noisy poses with DBSCAN, and converting Euler angles to quaternions. Each model takes a single frame and regresses the camera's position and orientation (a quaternion), trained with a PoseNet-style loss (position MSE plus a β-weighted, normalized quaternion term). We compared four architectures: ResNet50 with a linear head, ResNet50 features with Transformer encoders, a Vision Transformer (ViT-B/16), and ResNet50 features compressed by an encoder bottleneck (2048 → 128).

  • Course–Career Mapping via Data Visualization Spring 2024

    SM-Data Competition, Sookmyung Women's University · Excellence Prize

    • Built a word-cloud system linking coursework to employment outcomes.

    Using the university's curriculum data (2020–2023) and graduate employment data (2016–2021), the project linked each course to the major competencies listed in the curriculum, extracted the nouns from those competency descriptions with KoNLPy, and turned the competencies of the courses a graduate took into a word cloud. Given a student ID, the tool draws that graduate's word cloud, so one can see at a glance how their coursework relates to the job they took.
